# Painter Features v1 execution records

This directory contains subordinate, hash-bound execution objects. It does not contain a second
method plan. The sole canonical research method remains
[`../MEASUREMENT_PROTOCOL.md`](../MEASUREMENT_PROTOCOL.md).

`COLLECTION_FREEZE_1.json` narrows the first operation to preservation-only acquisition of eight
previously unused NGA files. It authorizes no normalization, feature extraction, model access,
human task, external confirmation, or painter claim. Historical AIC files remain historical and
may be referenced only as already-exposed development material.

The collector cannot run from the design object alone. It requires a separate authorization seal
that binds both the unchanged design hash and an approved independent review record. This avoids
the circular mistake of editing the reviewed object to record its own review.
