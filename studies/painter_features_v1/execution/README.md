# Painter Features v1 execution records

This directory contains subordinate, hash-bound execution objects. It does not contain a second
method plan. The sole canonical research method remains
[`../MEASUREMENT_PROTOCOL.md`](../MEASUREMENT_PROTOCOL.md).

[`COLLECTION_FREEZE_3.json`](COLLECTION_FREEZE_3.json) narrows the operation to
preservation-only acquisition of four NGA
files that were present in an old metadata census but had no located repository pixel exposure.
It authorizes no normalization, feature extraction, model access, human task, external
confirmation, or painter claim. Historical files remain historical and may be referenced only as
already-exposed development material.

The collector cannot run from the design object alone. It requires a separate authorization seal
that binds both the unchanged design hash and an approved independent review record. This avoids
the circular mistake of editing the reviewed object to record its own review.

Freeze 3 was approved and executed: 4/4 files were admitted without retry, redirect, replacement,
or fallback. See the
[`collection report`](../../../reports/painter_features_v1/COLLECTION_REPORT.md) and its compact
[`result artifact`](../../../reports/painter_features_v1/evidence/collection_result.json).

Rejected collection freezes and their exact skeptical reviews are under [`../old/rejected/`](../old/rejected/).
They are retained as failure evidence and authorize nothing.
