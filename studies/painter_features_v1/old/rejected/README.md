# Rejected Painter Features v1 execution designs

These artifacts preserve exact failed execution proposals and skeptical review findings. They are
noncanonical and authorize nothing.

Collection Freeze 1 proposed eight NGA works as unexposed qualification material. Independent
review showed that all eight had already been acquired and measured in Pilots 0/1. The design was
rejected before any request was sent. Its JSON, frame, availability calculation, and exact review
record remain here so the identity-normalization failure cannot be repeated.

Collection Freeze 2 corrected the exposure error but did not completely revalidate preserved raw
files and durable intents on a no-op rerun, and it did not enforce expected delivery geometry.
It too was rejected before any request. The exact reviewed collector is retained alongside its
freeze, frame, and review record.
