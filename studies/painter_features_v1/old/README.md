# Archived painter-features v1 design documents

Everything in this directory is **noncanonical**. These files are retained only to preserve the
review and revision history that preceded version 2.0 of the painter-feature measurement method.

The single canonical research plan is
[`../MEASUREMENT_PROTOCOL.md`](../MEASUREMENT_PROTOCOL.md).

Archived files:

- [`VALIDATION_PROTOCOL.md`](VALIDATION_PROTOCOL.md) — superseded validation-gate formulation.
- [`ANALYSIS_AND_CLAIMS.md`](ANALYSIS_AND_CLAIMS.md) — superseded analysis and claims policy.
- [`rejected/`](rejected/) — immutable rejected execution designs and their exact skeptical
  reviews. Rejection records are evidence, never authorization.

Do not combine clauses from these archived documents with the canonical protocol. If an archived
rule appears absent from the canonical protocol, treat it as retired unless a new numbered
canonical revision restores it explicitly. Git history remains the authority for the exact
pre-archive versions and review sequence.
