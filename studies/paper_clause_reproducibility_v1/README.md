# Prospective clause study: public numerical addendum

This additive namespace packages `painter_clause_validation_v1` and optionally
its one fixed `painter_clause_successor_v1` Cezanne/generic cohort in the same
archive. It changes
no sealed scientific source, protocol, result or earlier public release. Its
coverage is exact replay of each cohort's primary comparisons and their withholding,
all specified secondary summaries, delivery counts and the unchanged report
from compact measurements. It neither re-extracts images nor authenticates
absent raw responses, remote model identity or reference artwork.

The cohorts retain separate inputs, terminal receipts, source/freeze provenance,
analyses and reports. They are never pooled. Original unavailable endpoints stay
unavailable: their retained Holm value 1 is family bookkeeping, not a computed
p-value or evidence of non-rejection. Successor alpha stays .025 even when the
original comparisons are unavailable.

After terminal measurement/report receipts exist and the source, tool, tests,
design and original results are committed in the retained checkout:

```sh
uv run --locked python tools/paper_clause_release.py export --release-id RELEASE_ID
```

For the intended combined addendum, wait for both terminal measurement/report
receipts and add `--include-successor` to that export command. The option accepts
only the fixed `pcsv1-20260910` successor. Both cohorts are fully validated before
any compact export file is created. Build, verify and check discover the optional
cohort from the bound export descriptor; they need no extra study selection.

Commit the create-once export, then stage its final archive:

```sh
uv run --locked python tools/paper_clause_release.py build --release-id RELEASE_ID \
  --output-root tmp/paper-clause-release
```

The stage, deterministic archive and archive checksum are create-once. A separate
`--draft` build skips only final Git checks for local QA; scientific bindings and
payload hashes still must match. Never overwrite an export or use a draft as a
final scientific release. Publishing and fresh anonymous replay are separate
coordinator actions; this tool performs no publication or network operation.

The public root README gives the supported `verify`, dependency installation and
`check` commands. Verify uses only the standard library before installation.
Installation selects Python 3.13.11 explicitly, matching the interpreter in the
export descriptor's `freeze_environment`, and uses the unchanged lockfile.
Check runs unchanged numerical functions without the study workflow, local Git,
proxy, response files or image archive. Some inert transport-related source is
imported by the unchanged common module; no transport function is executed.
The copied collection/workflow source is for inspection, not a supported public
generation or measurement interface. Explicit tests cover numerical replay and
package safety. Optional tests require Git for temporary provenance fixtures;
maintainer-only terminal-workflow tests are explicitly skipped when their
excluded workflow dependencies are absent. The original full project CLI is
not a supported entry point.

The exporter verifies terminal local metadata and commits before projecting
measurement rows to the exact consumed identity, numerical and delivery fields.
Successor local verification additionally authenticates the predecessor's
error-only refusal trigger; it does not read generated-image response bodies.
Assigned requests and safe original collection metadata remain verbatim. The
original private freeze is represented by a clearly labeled provenance record:
source/qualification commits, bound paths/hashes, environment and the hash of the
omitted proxy snapshot. Recorded relative path/hash references to absent runtime
files are provenance and are never traversed by public replay.

Only explicit source, design, qualification, precision, review, reference/scaler/
map inputs and compact result files are included. The package excludes image
pixels, response bodies, proxy snapshots, keys, `.env`, Git history, literature
full text, weights, external source checkouts, Korean drafts and manuscript files.
Code/numerical-export licensing grants no rights to absent underlying artwork.
Earlier paper findings require their immutable original numerical releases.

The adapter and its review are maintainer-run LLM work. Its author also assisted
with the original study's precision module, successor analysis and earlier
variance primitives. Exact replay
does not establish independent investigators, population generalization, a
stable service checkpoint, no interference or human-perceived style.
