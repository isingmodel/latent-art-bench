# Sensitivity to reference content mixture

Declared before extraction or inspection of the new specificity experiment's
feature outcomes. Generation is already running; its frozen allocation and
primary endpoints remain unchanged. No new images, annotations or paid requests.

The reference painters have different recorded subject mixtures. Water-organized
works constitute 64.3% of Monet but 19.9% of Pissarro, for example. This can
influence their feature contrasts even when generated scene text is common.
Use all 649 existing reference vectors and their previously recorded four-class
coding in `pfg2-frame-20260905/frame.jsonl`. The four classes are water-organized,
built-place-organized, route-organized, and open/wooded land. Every artist has
observations in all classes; the minimum class size is eight.

Within each painter, replace the unweighted reference mean with the equally
weighted mean of its four class means. Keep all generated data, all 31 features,
the separate scaler, artist centering and repeat-corrected estimators unchanged.
Report the resulting reference-contrast cosine and squared magnitude relative to
the original target, all six model slopes/errors, their amplitude/orthogonal
components, and all 15 paired model differences. Use the existing minimum of
12 complete paired scenes. Intervals are descriptive; this sensitivity adds no
confirmatory tests or route to primary significance. Repeat in the common-square
view without choosing between representations.

Also resample reference works 1,000 times within each artist/class stratum, keeping
class weights fixed at one quarter and generated outputs fixed (seed 2026091101).
This assesses uncertainty in the reweighted reference target conditional on class
coding. It does not account for annotation error, match individual compositions,
validate requested output content, or isolate pure style. Broad class labels are
existing maintainer annotations; they are not new independent human judgments.
The new authored scene categories are not equated with these reference classes.

This changes the finite reference target and its normalizing magnitude H.
Absolute D values across the original and balanced targets therefore have different
units. Model ordering within a target, contrast signs and reference-aligned
responses can be compared descriptively. Disagreement would identify reference
content mixture as an interpretation limit, not prove that content causes the
entire generated/reference gap.

Source, this plan, old class metadata, reference/scaler and the active experiment
freeze are bound before new measurement. Analysis is allowed only after the
active experiment closes and its measurements pass their own receipt verification.
