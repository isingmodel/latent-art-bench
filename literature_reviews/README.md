# Literature evidence base

This directory retains the literature review developed for the original painter-
feature protocol. It is historical methodological context, not the current study
status. The current paper's focused comparison is in
[its literature matrix](../studies/painter_distribution_revision_v1/LITERATURE_MATRIX.md),
and its citations are in [paper/references.bib](../paper/references.bib).

| File or directory | Purpose |
|---|---|
| [SEARCH_PROTOCOL.md](SEARCH_PROTOCOL.md) | Search, screening, extraction and grading rules, with retrospective limitations |
| [SEARCH_LOG.md](SEARCH_LOG.md) | Reconstructable searches and citation chasing |
| [EVIDENCE_MATRIX.csv](EVIDENCE_MATRIX.csv) | 144 primary-source or standard records with evidence grades and methodological implications |
| [BIBLIOGRAPHY.md](BIBLIOGRAPHY.md) | 205 checked citations and primary-source links |
| [reviews/](reviews/) | Six thematic reviews: interpretable features, learned representations, digitization, human validation, statistics and generated-art fidelity |
| [SYNTHESIS.md](SYNTHESIS.md) | Comparison across feature families |
| [METHOD_DECISIONS.md](METHOD_DECISIONS.md) | Retained, diagnostic and rejected approaches in the original protocol |

The records distinguish color, texture, composition, information-theoretic,
learned-appearance and contextual constructs. They do not establish that any
single image statistic measures painter style. There is no complete detailed
evidence card for every matrix row; the search protocol records that limitation.

Retain the substantive records as written. Future literature updates should
identify their own search scope and date. See [current status](../docs/STATUS.md)
for completed studies and [artifact retention](../docs/ARTIFACTS.md) for the
ignored local literature PDFs and source files.
