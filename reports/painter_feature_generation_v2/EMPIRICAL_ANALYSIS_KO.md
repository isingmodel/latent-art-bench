# 사용 가능한 이미지 생성 서비스: 화가 특징의 실증 분석

> 이 문서는 [영문 분석 보고서](EMPIRICAL_ANALYSIS.md)의 한국어 번역본이다. 수치와 연구상의 한계를 원문대로 유지하며, 해석에 차이가 있을 경우 봉인된 영문 원본과 그에 연결된 증거 자료를 기준으로 한다. 번역본은 원본의 증거 기록을 대체하지 않는다.

논문 원고가 아닌 분석 보고서. 기록일: 2026-09-05. 방법 식별자: `pfg2-method-20260905`.

## 결과와 해석

고정 작품 목록에는 1,193점이 포함되어 있다. 이 중 1,185점의 이미지를 확보했고, 1,180점의 측정에 성공했으며, 유한 참조 집합에는 649점이 포함된다. gpt-image-1, gpt-image-2, sd-turbo에 대해 측정을 완료한 비교 결과를 제시한다.

**화가 특징의 재현이 입증된 것은 아니다.** 이 분석은 분포 간 차이와 화가명 지정 조건·대조 조건 간 차이를 측정하며, 동등성을 입증하지 않는다. 독립 촬영본을 이용한 보정·검증과 타당한 근거를 갖춘 동등성 허용 한계는 아직 확보되지 않았다. 포함률 점검 결과에 따라, 명목 95% 구간을 검증된 신뢰수준 보장으로 취급할 수 없다.

| 요청한 서비스 / 기준 모델 | 조건별 이미지 수 | 화가명 지정 − 대조 조건 차이가 음수인 경우 | 색상 / 공간 / 질감별 집계 | 지정 화가가 나머지 세 화가 모두보다 가까운 경우 |
| --- | --- | --- | --- | --- |
| gpt-image-1 | 16 | 7/12 | 4/4, 1/4, 2/4 | 8/12 |
| gpt-image-2 | 16 | 7/12 | 3/4, 2/4, 2/4 | 9/12 |
| sd-turbo | 400 | 10/12 | 3/4, 4/4, 3/4 | 4/12 |

이는 부호의 기술통계적 집계이며, 유의성 검정이나 순위가 아니다. 전체 비교의 분모는 네 화가 × 세 특징군이다. 생성 표본 수의 차이는 유한 집합의 V-통계량에 영향을 미친다. OAuth 서비스 별칭별 실험은 한 번만 반복되었으며, 실제 사용된 모델 스냅샷은 확인되지 않았다.

화가명을 넣지 않은 대조 조건 대비 개선과 화가 특이성은 서로 다른 질문에 답한다. 대조 조건 대비 차이가 더 유리하다는 것은 화가명을 넣지 않은 기준 조건이 더 약하기 때문일 수 있으며, 화가명을 지정했을 때의 절대적인 적합도가 더 좋다는 뜻은 아니다. 대조 조건보다 개선되었다고 해서 지정 화가가 다른 모든 화가보다 가까운 것은 아니며, 어느 성질도 동등성을 입증하지 않는다.

## 사전 등록한 실험과 관측된 서비스 동작

SD-Turbo는 체크포인트 `b261bac6fd2cf515557d5d0707481eafa0485ec2`를 사용하며, 로컬 FP16 MPS 환경에서 512×512, 한 스텝, guidance 0, 대응 시드 블록 25개로 실행했다. OAuth 예비 실험에서는 사용 시점을 기록한 로컬 Codex OAuth 프록시를 통해 `gpt-image-1`과 `gpt-image-2`를 요청했다. 각 별칭에 대해 정확히 고정된 템플릿 16개 × 다섯 조건 × 한 번의 반복을 모두 실행했다. 시드는 제공하지 않았다. 미적 기준에 따른 선별, 마음에 들지 않는 결과의 재생성, 유료 API로의 대체 실행은 하지 않았다.

| 별칭 | 최종 처리 결과 | 디코딩한 이미지 크기 | 응답의 품질 메타데이터 | 응답의 모델 식별자 |
| --- | --- | --- | --- | --- |
| gpt-image-1 | {'generated': 80} | 19종; 최빈 크기 1402×1122 (29/80); 가로형 80/80 | {'low': 80} | {'None': 80} |
| gpt-image-2 | {'generated': 80} | 16종; 최빈 크기 1402×1122 (25/80); 가로형 79/80 | {'low': 80} | {'None': 80} |
| sd-turbo | {'generated': 2000} | 1종; 최빈 크기 512×512 (2000/2000); 가로형 0/2000 | {'None': 2000} | {'None': 2000} |

표의 `generated`는 생성 완료를 뜻한다. `low`는 응답에 기록된 품질 설정값이며, 결과물의 미적 품질에 대한 평가가 아니다.

OAuth 요청 설정은 1024×1024 / medium / PNG였다. 실제 반환된 이미지의 가로·세로 크기와 품질 메타데이터는 별도로 보존했다. 정규화를 수행했다고 해서 요청한 조건이 소급하여 충족되는 것은 아니다. `None`은 모델 식별자가 반환되지 않았음을 뜻하며, 동일한 모델이 사용되었음을 확인했다는 뜻이 아니다. SD-Turbo는 응답에 보고된 설정이 아니라 로컬 체크포인트에 명시된 실행 조건을 따른다. 지연 시간과 요청·응답 간 모든 불일치는 수치 결과에 기록되어 있다.

원래 종횡비를 보존하므로, 정사각형 SD-Turbo 이미지와 OAuth 서비스가 반환한 이미지는 가로·세로 형태가 통제된 비교가 아니다. 짧은 변을 같은 길이로 정규화해도 이러한 공간·질감상의 교란은 제거되지 않는다. 이전의 중립 이미지 접근 점검에서 반환된 1254×1254 이미지는 별도 증거이며, 이번 화가별 실험 조합에서 생성된 이미지의 크기를 뜻하지 않는다.

실제 회화 이미지의 원래 크기로 보고한 값은 확보한 Commons 렌더링 이미지의 크기이다. 반드시 최초의 원본 해상도 사진이나 물리적 캔버스를 나타내는 것은 아니다.

## 작품 집합, 탈락 현황과 측정

실제 작품의 고정 목록은 Wikidata에 야외 장소를 묘사한 회화로 기재된 작품들이다. 기관이 검증한 작가 귀속 목록이나 화가의 전체 작품 세계에서 추출한 확률 표본이 아니다. 탈락이 발생해도 작품에 배정된 역할은 바뀌지 않는다. 과거 노출 기록과의 대조를 통해 91개 기록을 개발 전용으로 배정했다. 제외 목록의 14개 기록에는 서로 연결할 식별자가 없었으므로, 정보 누출이 없었다고 입증할 수 없다.

모든 실제 회화 이미지는 오류를 수정한 R2 렌더링 확보 실행 전체에서 가져왔다. 이전의 원본 이미지 확보 실행과 첫 렌더링 확보 실행은 종료되었으며, 그중 일부 성공분을 R2에 이어 붙이지 않았다. 수정 사항은 Wikimedia의 새 썸네일 호스트와 실제로 안내된 썸네일 크기를 반영한 것이다. 작품을 추가하거나 기준값을 낮추지 않았다. [Wikimedia 호스트 이전](https://phabricator.wikimedia.org/T434821); [Imageinfo의 크기 처리 방식](https://www.mediawiki.org/wiki/API:Imageinfo/en).

공통 측정 방법은 이미지를 완전히 디코딩하고, EXIF 정보를 적용하며, 유효한 ICC 프로파일에 따라 sRGB로 변환한다. 프로파일이 없으면 sRGB로 가정했음을 표시한다. 종횡비를 유지하고 확대 없이 짧은 변이 512가 되도록 축소한다. 색상 특징 11개, 공간·방향성 특징 여덟 개, 디지털 질감 특징 12개를 측정한다. 화가별 가중치를 동일하게 둔 공통 중앙값/IQR(사분위 범위) 변환은 신규 개발 집합만으로 적합한다. 방법 점검 집합은 진단용이며, 이를 이용해 방법을 선택하지 않는다.

개발 집합과 방법 점검 집합 사이의 유한 에너지 거리는 동일한 512픽셀 신규 개발 집합 기반 척도 변환을 사용한다. 이는 참조 집합 진단값이지 동등성 허용 한계가 아니다. 이 값들을 보고 분석 파이프라인을 선택하지 않았다.

## SD-Turbo 반복 실험의 불확실성과 보정·검증

SD-Turbo 생성 과정에 대한 추정량은 생성 집합 내부의 거리 항에서 같은 반복 블록에 속하는 쌍을 제외한다. 따라서 위의 유한 집합 표와 다르며, 값이 음수일 수도 있다. 부트스트랩 재표집 9,999회는 유한 실제 작품 참조 집합을 고정한 조건에서, 전체 60개 평가 항목에 걸쳐 블록 전체를 함께 재표집한다. 구간은 명목적·탐색적 결과이며, 검증된 검정 결과가 아니다.

## 연구 논문 수준의 주장에 앞서 남은 과제

이번 작업으로 사전 등록한 기술통계 목적의 실험을 완료한 범위는 실험 조합 및 측정 관문을 통과한 부분에 한정된다. 더 강한 모델 수준의 연구를 위해서는 OAuth 모델의 신원을 입증할 정보와 제어 가능한 설정, GPT 실험 조합의 반복 실행, 더 충분히 검증된 불확실성 평가, 실제 독립 촬영본과 근거 있는 동등성 허용 한계가 필요하다. 소재, 촬영·디지털화 작업 절차, 테두리, 학습 데이터 중복도 더 잘 통제해야 한다. 이 자료로 물리적 붓질, 내용과 분리된 화풍, 예술적 의도, 저자성, 화가의 전체 작품 세계에 걸친 재현을 입증할 수는 없다. 모든 점검은 운영자 또는 LLM의 도움으로 수행되었으며, 기관 차원의 독립적 검토를 받았다고 주장하지 않는다.

## 증거 자료와 분석 재현

[방법 증거 디렉터리](../../data/manifests/painter_feature_generation_v2/pfg2-method-20260905/)에는 공통 방법 동결 기록, 확인 집합의 단 한 번의 개봉 기록, 척도 변환, 접근 원장, 단계별 증빙 기록, `empirical_analysis.json`, 실험별 `analysis.json`, 크롭 증거가 들어 있다. 원본 보고서의 모든 표는 이 수치 산출물에서 생성되었다. 동결된 입력의 해시는 특정 커밋에 연결되어 있다. 원시 미디어, HTTP 본문, 모델 가중치는 버전 관리에서 제외된 연구 작업 공간에 유지하며 재배포하지 않는다. 종료된 연구 실행을 같은 기록에서 다시 실행하지 않는다.

[사전 등록된 실증 분석 개정안](../../studies/painter_feature_generation_v2/PROTOCOL_1.2.md)은 추정 대상과 한계를 정의한다. [이전 접근 보고서](AVAILABLE_IMAGE_MODELS.md)는 이번 화가별 실험 조합과 별개인 중립 이미지 전송 평가를 기록한다. 측정 근거는 [Székely와 Rizzo의 에너지 통계](https://doi.org/10.1016/j.jspi.2013.03.018)이며, [고정 리비전의 SD-Turbo 모델 카드](https://huggingface.co/stabilityai/sd-turbo/blob/b261bac6fd2cf515557d5d0707481eafa0485ec2/README.md)는 로컬 모델의 실행 조건을 정의한다.

```bash
uv run --locked --extra analysis --extra learned ruff check .
uv run --locked --extra analysis --extra learned pytest -q -m "not live"
uv run --locked --extra analysis --extra learned latent-art-bench verify-evidence
uv run --locked --extra analysis --extra learned latent-art-bench paper-study audit
```
