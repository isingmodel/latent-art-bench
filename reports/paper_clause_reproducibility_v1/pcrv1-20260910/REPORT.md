## Scope of verification

Both fresh replays ran on the same macOS arm64 host, using cached locked packages;
no hosted Linux result is claimed for this addendum. Maintainer-run LLM agents
performed implementation and verification with their involvement disclosed.
This is public numerical reproducibility, not replication by independent
investigators, perceptual measurement validation, independent-capture validation,
or authentication of an upstream model checkpoint.

The public archive contains the protocols, source, prompts, qualification and
precision records, scalers/reference vectors, assigned statuses and complete
reports. It excludes artwork, generated pixels, raw response bodies, credentials,
proxy snapshots, literature full text, weights and Korean drafts. Licensing the
code and numerical exports grants no rights to absent artwork.

Earlier manuscript results require the unchanged [original release](https://github.com/isingmodel/latent-art-bench/releases/tag/pprv1-20260910)
and [geometry addendum](https://github.com/isingmodel/latent-art-bench/releases/tag/ppgv1-20260910).
The three packages retain separate commands and scope; successful clause replay
is not a replay of the entire paper.
