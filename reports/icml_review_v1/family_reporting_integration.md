# Prospective reporting integration

19 September 2026. **Offline preparation, no new service observations.**

New adapters connect a closed4,608-slot collector census to exact image IDs,
original bytes, retained raw responses, actual attempt times and missing cells.
Two learned-vector manifests bind the historical CLIP/CSD checkpoints and native
preprocessing; a raw31 manifest binds the original512-pixel measurement routine
and historical development-only scaler. Every successful collector image must
have exactly one vector per supplied representation. An extraction failure
cannot silently become an omitted collector observation.

The combined report requires both encoders, all four reference panels and the
raw31 representation on the same census. It selects CSD/primary-original for
the fixed12-endpoint primary, retains the other seven reference/encoder pairs
as secondary, applies both old-only recognition controls and includes the
new [v4 realized-energy secondary](prospective_controls_v4.md). Pure report
functions have nine constructed selection/missingness tests.

The [pipeline fixture](../painter_family_controls_v1/offline_reporting_v1/result.json)
uses four mock successful images and4,604 explicitly missing slots. It loads
the independently bound reference and transport candidates, authenticates the
supplied fixture row manifests, maps vectors to full fixed axes and emits all
report branches. All primary decisions remain unavailable because the required
eight-window panels are incomplete. Default simulation use is rejected; the
explicit fixture run retains its simulation label. Its compressed report and
input records are archived, and only its temporary fixture files were removed.

The learned vectors and raw31 rows in this fixture are intentionally invented.
No encoder or31-feature extractor was executed. This integration validates
identity, axes, missingness, report selection and serialization; it does not
authenticate actual extraction, establish a scientific effect, or justify a
new reviewer score. Execution receipts and replay remain a separate pending
step before real feature artifacts can support empirical claims.

The31-feature loader and tests were substantially written by a sub-agent whose
turn ended at an execution quota. Root inspected the saved files, completed
lint cleanup, ran the targeted suites and exercised the loader in the combined
fixture. No independent scientific rating is attached to this work.
