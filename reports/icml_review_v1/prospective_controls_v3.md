# Precollection corrections to the proposed family-control study

19 September 2026. **Design revision only; not frozen, authorized or executed.**
This addendum incorporates the independent
[methods audit](prospective_controls_method_audit.md). It preserves the previous
[full proposal](prospective_controls_v2.md) and supersedes the points below.
The six configurations, all four painters, 12 exact scenes, eight exact arms,
eight windows and total allocation of **4,608 images** remain unchanged. The
smaller allocation in the audit is an alternative, not an adopted reduction.
No human evaluation, paid pilot, download or old collector restart is included.

## 1. Supported operational claim

Retain the primary `N` and `T = F - 0.5 N` definitions and the twelve-endpoint
simultaneous criterion from v2. The tested question is whether this exact
**name-free family prompt as a whole** produces more than half the aggregate
prototype gain of the named prompts relative to generic painting, on this
fixed workload. A positive result shows that the gain can be produced without
individual painter names. It does not identify what caused or mediated the
gain in the named prompts. A negative result says that this comparator did not
meet the declared criterion; it does not exclude a shared-family mechanism.

`S` and `F-S` remain complete secondary comparisons. The primary family suffix
contains wording and historical-family information together. Do not describe
the primary contrast as isolating the latter, switch baselines after seeing
outcomes, or claim that common movement is necessarily unwanted.

## 2. Temporal target and ratios

The primary target is the equal-weight average of expected condition effects
for the fixed 12-scene panel over the eight scheduled windows. Retain the four-day
schedule in v2 so the pending resource proposal does not silently become an
eight-day commitment. Report actual start/completion times and all eight values.
The Student procedure assumes independent, suitably behaved window summaries;
two windows per day are not eight independently sampled days. Correlation
multipliers remain assumption-indexed sensitivities, not measured corrections.

Fieller ratios concern **ratios of averages over sessions**, using the paired
numerator/denominator covariance. They are not averages of per-session ratios.
Retain negative or zero denominators and unbounded or disconnected confidence
sets. No ratio replaces the linear primary criterion. Constructed-case tests
must establish these behaviors before the final freeze.

Drop the proposed new cross-session squared-error comparison from the analysis
contract. With changing conditional means, cross-session products do not target
either session's squared error; treating same-day versus different-day products
as a covariance estimate is unsupported. The linear primary endpoints, absolute
common/labeled components and recognition outcomes answer the declared question
without this ambiguous secondary diagnostic. This changes no existing result.

## 3. Frozen old-to-new recognition control

Add a prespecified **secondary** transport test without additional generation:

- For each of the six configurations and each already fixed encoder, fit one
  common translation and four supervised generated prototypes using all named
  observations from the old 14-scene cohort. Use only the original full-frame
  primary reference target for this prospective control. Freeze arrays, source
  hashes, code and decisions before seeing any new image or feature.
- Let `mu_a` be each raw historical mean, `u_a` its normalized prototype,
  `g_bar` the equally balanced old generated mean, and
  `t = mean_a(mu_a) - g_bar`. Freeze scale one. The three rules are the unchanged
  baseline `argmax x.u_a`, translated `argmax (x+t).u_a`, and supervised
  `argmax x.q_a` with normalized old generated class means `q_a`.
- Apply these fixed rules to every new named query. Do not fit with the new
  pool, reweight its names, select an encoder/source view or tune any offset
  using the new outcomes. Use the retained painter order to resolve exact ties;
  retain ties, zero-query flags and all signed score margins.
- Report every paired correction/harm, class confusion and recall, and accuracy
  difference by configuration, encoder and window. Aggregate windows equally.
  If any named cell is missing, report the incomplete census; do not silently
  change the fixed-panel estimand or replace missing requests.
- This evaluates transport to later requests and new scene wording jointly.
  It does not distinguish content changes from service changes, authenticate
  served checkpoints, or estimate artistic fidelity. Secondary descriptive
  results cannot replace the primary decision or acquire unadjusted
  confirmatory significance claims.

## 4. Required collector qualification

The old collector does not implement this proposal and remains terminal.
A separate, initially offline collector must pass the following constructed,
no-network checks before any live dispatch is permitted:

1. Exact 4,608-cell membership, global within-window ordering and no automatic
   paid qualification pilots.
2. Admission only inside the assigned four-hour window; retries stay in it.
   A request started before cutoff is drained and retained under its original
   assignment even if it completes later. No late backfill into another window.
3. Durable intents, exclusive run ownership, crash recovery, partial archives,
   permanent terminal closure and an explicit incomplete census.
4. Approved cumulative accounting and outstanding $5 reservations, at most
   three active requests, five seconds between starts, per-slot and global
   retry caps. An error with unverified charge keeps its reservation and pauses
   dispatch; it is not automatically zero-cost or eligible for retry on resume.
5. Actual free-space admission on every write volume, retaining the 5 GiB floor
   and 256 MiB per active-request reservation. The 40 GiB planning requirement
   is separate. No unique source data is deleted to satisfy admission.
6. Decode and retain original bytes and detected media type. Expected output is
   one 1,024-by-1,024 image. Unexpected count/dimensions or contradictory echoed
   model/provider metadata is a technical mismatch: preserve the response,
   pause starts and report it; no silent resizing or replacement. Absence of
   an echo remains missing attestation, not proof of a match.

These are implementation requirements, not claims that a qualified collector
already exists. Freeze exact payloads, UTC windows, analysis, tests and financial
and storage configuration together after current routes/prices are verified.

## 5. Resource and scientific boundaries

The existing approved cumulative ceiling remains **strictly below $120** and
recorded historical accounting remains **$112.293676**. The proposed increase
to **$350**, estimated **$200.166062** new charges and a destination with
**at least 40 GiB actually free** await the user's decision. No new acquisition
is authorized by this addendum. Current local capacity is insufficient.

The study would add independent requests with a contemporaneous family control
and a frozen transport test. It would retain the same four painters and finite
historical reference target. It would not supply independent reference images,
perceptual truth, arbitrary service-independence guarantees or a promised review
score. Exact-pixel publication remains a separate unfinished artifact task.
