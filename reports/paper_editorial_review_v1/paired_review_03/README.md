# 원고 수정 → 새 세션 평가 → 재수정

이 문서는 재수정 완료 당시의 기록이다. 이후 같은 최종본에 대한
[마지막 평가 `_04`](../paired_review_04/README.md)가 추가됐으며, 그 뒤 원고는
변경하지 않았다. 아래 `_03` 점수와 당시 스냅샷 기록은 그대로 보존한다.

사용자가 요청한 순서대로 먼저 round 33 원고를 고치고, 그 수정본을
새 Claude Code 세션과 대화 이력 없는 Astra 요청으로 평가한 뒤 다시 수정했다.
현재 `paper/paper.pdf`는 마지막 재수정본이다. 아래 점수는 **재수정 전의
동결된 1차 수정본**에 대한 것이며, 현재 최종본의 평가 점수로 간주하지 않는다.

Claude의 이전 별도 평가는 8.3125, Astra는 8.9375였다. 새 평가는 모두
그보다 낮았으며, 이를 숨기거나 점수를 보정하지 않았다. 서로 다른 독립
판단이므로 점수 차이만으로 수정 효과를 단정하지 않는다. 이 기록은 기존
33개 라운드의 세 평가자 목표를 대체하거나 그 평균에 합산하지 않는다.

## 평가 후 반영한 내용

1. **초록의 목적 설명:** 평균을 빼는 절차를 먼저 나열하던 문장을,
   화가별 차이와 공통 변화를 분리하기 위한 비교라는 설명으로 바꿨다.
   유화 지시의 기여, 보정 전후 순위, 지각적 충실도 한계는 유지했다.
2. **그림 2:** Overview 표기를 추가하고 확대 영역과 상세 패널의 테두리를
   진하게 했다. 크기, 축, 모든 관측점, 평균과 연결선은 보존했다.
3. **보정값의 주어:** 약 0.45배의 보정값은 GPT Image 2에 해당함을 명시했다.
4. **보정 후 비교 근거:** 원본 영역 수정과 스케일 재추정 후 여섯 모델의
   오차 및 보정 오차를 부록 C.5에 한 문단으로 제시했다. 기존 보고서의
   수치만 옮겼으며 새 분석은 실행하지 않았다.
5. **계산 정의:** 부록 C.1에서 분자와 분모가 같은 11개 장면의 평균임을
   명시하고 S = 11을 정의했다. 부록 B.2에는 회귀의 기준 모델을 바꿔도
   비교 차이는 변하지 않는다는 설명을 넣었다.
6. **용어와 흐름:** brief를 고정된 장면 설명으로 정의했다. 공통 변화의
   장면 평균 방식과 장면별 방식의 차이를 짧게 설명했다. 중복된 일반적
   제한 문구, 정보가 없는 서론 끝 문장, 결과 없이 소개하던 전체 라벨
   순열 설명을 덜어냈다. 본문의 Monet–Sisley 교환 결과는 유지했다.

## 그대로 채택하지 않은 제안

- **그림 축을 ±2.5로 줄이기:** 실제 점은 x −2.069~3.649,
  y −2.565~4.087에 걸친다. 제안대로 줄이면 점이 잘린다. 전체 그림을
  없애는 대안도 네 화가와 장면 변동을 함께 보여 주는 기능을 잃으므로,
  Astra가 제안한 표기와 테두리 개선만 적용했다.
- **장면 평균 비율을 쓰는 이유가 D와 같은 계산이기 때문이라는 설명:**
  D는 장면별 오차의 평균이고, 평균 대비의 오차와 장면 변동을 모두
  포함한다. Claude가 제안한 이유는 잘못됐다. 실제 구분인 일관된 이동과
  장면별 변동을 설명하고, 두 비율을 함께 밝혀 혼동을 해소했다.
- **절 4.4 통합·전체 비교표의 본문 이동:** 보정 절차와 사후 진단의 위치를
  보존했다. 본문에는 핵심 비교를, 부록에는 전체 15개 비교를 유지하는
  편이 현재 분량에서 읽기 쉽다. Astra도 이 구성을 강점으로 평가했다.
- **모든 소수 표기를 일괄 변경:** 수치 의미의 오류가 없는 낮은 우선순위
  형식 제안으로 남겼다. 이번 수정은 정의, 비교 근거와 그림의 가독성에
  집중했다.
