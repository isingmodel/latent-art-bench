## Contract examined

The optional combined export admits only the fixed successor
`painter_clause_successor_v1/pcsv1-20260910`. Both cohorts are validated before
the first compact export file is written. Each local terminal wrapper calls
its unchanged sealed workflow, then requires the exact four measurement-output
bindings, their hashes, the collection-receipt chain and every allocated
request/pipeline status: 288/864 for the original and 96/288 for the successor.
The successor workflow additionally authenticates the predecessor's error-only
refusal trigger. No generated-image response is read by this packaging path.

The two compact input bundles, original outputs, provenance records, analyses
and reports remain separate. The adapter invokes each unchanged `analyze` and
`report_text` function; equality is exact rather than tolerance based. The
original identity failure and withheld endpoints remain unchanged. Its retained
Holm value 1 is explicitly described as unavailable-family bookkeeping rather
than a computed p-value. The successor retains its single .025 threshold.
No pooled endpoint or recovered original comparison is produced.

The successor's numerical-input lineage is checked as an exact canonical-JSON
projection: the predecessor input path/hash, Cezanne target masses, full
reference cells and full retained scaler objects must agree. Public provenance
also links the successor to the original freeze, collection receipt, source
commit and refusal-trigger identity. These checks run before local export and
again during package gathering; they do not traverse absent private paths.

The combined allowlist has 71 core files, including 40 scientific source files
for the numerical import closure and selected source kept for inspection.
There are 85 files in the complete synthetic archive after adding both cohorts'
compact inputs, original outputs and package manifests. No arbitrary study or
module name can expand this inventory. Source/design bytes are checked against
the applicable freeze and source commit; final export/build also require exact
working-tree, index and HEAD bytes. Outputs are create-once.

Rows retain only consumed identity, raw/scaled feature vectors, status and
delivery fields. Safe collection metadata remains verbatim. Private proxy
contents are omitted and represented by their hash. Strict relative-path,
symlink, inventory and metadata-content checks exclude runtime bodies, image
pixels, credentials, Git history and other unlisted payloads. Python source is
copied from the reviewed static allowlist, not discovered from runtime paths.

Public `verify` uses the standard library before dependency installation.
Public `check` imports unchanged numerical/common functions and verifies their
module origins; foreign cached scientific modules are rejected before and after
replay. Inert transport helpers remain in the common-module import closure, but
neither clause workflow nor collector is imported by numerical replay. The guide
correctly separates the optional tests' Git requirement and explicit local-only
skips from the Git-free verify/check commands.
