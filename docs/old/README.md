# Archived legacy planning and method documents

Everything in this directory is historical and noncanonical. These documents preserve rationale,
failed-plan analysis, and earlier method proposals from before the Painter Features v1 reboot.
They may be cited as provenance, but they do not authorize current research operations and must
not override the canonical
[`MEASUREMENT_PROTOCOL.md`](../../studies/painter_features_v1/MEASUREMENT_PROTOCOL.md).

The archive contains the former research proposal, benchmark/corpus/validation designs, feature
method notes, artist-selection rationale, project decisions and roadmaps, API testing notes,
implementation snapshots, failure investigations, and legacy references.

Frozen Pilot 2/3 protocols and hash-bound historical documents intentionally remain one directory
above this archive. Their literal paths are part of committed evidence, so moving them for cosmetic
consistency would damage verification. The same fixed-path rule applies to historical pilot config,
report, ledger, source, test, and script namespaces described in
[`ARTIFACTS.md`](../ARTIFACTS.md).

Use [`INDEX.md`](../INDEX.md) for the current document map and [`STATUS.md`](../STATUS.md) for
operational truth.
